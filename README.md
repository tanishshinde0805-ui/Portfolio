## Portfolio Features & Architecture

The website is engineered with vanilla web technologies to maintain high performance, accessibility, and zero runtime bundle overhead:

- **Interactive Theme Color Switcher:** A live styling tool that lets visitors switch between five distinct theme accents (`color-1` through `color-5`) at runtime by dynamically toggling active CSS stylesheets.
- **Dark & Light Mode:** Seamless toggle between light and dark visual themes with dedicated state handling in `style-switcher.js`.
- **Dynamic Subtitle Animation:** Configured with `Typed.js` to animate rotating roles and specializations in both the hero and about sections.
- **Viewport-Triggered Skill Bars:** Uses JavaScript's native `IntersectionObserver` API to animate skill proficiency percentage bars smoothly when the `#skills` container enters the viewport.
- **Single-Page Navigation:** Aside drawer with persistent icon links and a mobile toggler for fluid navigation across `#home`, `#about`, `#skills`, `#projects`, `#certificates`, and `#contact`.
- **Resume Download:** Direct link to download my latest PDF curriculum vitae (`cv/TanishShindeResume (3).pdf`).
- **Interactive Contact Section:** Frontend contact form with validation and instant user feedback acknowledgement.

## Local Setup & Development

To preview or inspect the portfolio locally on your machine, follow these steps:

### Prerequisites
- A modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari)
- [Git](https://git-scm.com/) installed on your system (optional, for cloning)

### 1. Clone the Repository
```bash
git clone https://github.com/tanishshinde0805-ui/Portfolio.git
cd Portfolio
```

### 2. Run Locally

Because the project is built with standard HTML, CSS, and vanilla JavaScript, it requires no package manager (`npm`/`yarn`) or compilation step.

**Option A: Direct in Browser**
- Simply double-click `index.html` or open it directly in your preferred browser.

**Option B: VS Code Live Server (Recommended)**
- Open the project directory in Visual Studio Code.
- Install the **Live Server** extension by Ritwick Dey.
- Right-click `index.html` and click **"Open with Live Server"** (default runs at `http://127.0.0.1:5500`).

**Option C: Python HTTP Server**
```bash
# Python 3
python -m http.server 8000
```
Open `http://localhost:8000` in your web browser.
